# Gedeeltelijke artiestscore uit historische incidenten
Eigenaar: huidige Codex-sessie. Branch task/artist-partial-risk-20261110.
Scope gedeelde scoreberekening, artiest-risicokaart en passende controles.
Hergebruik vertrouwelijke incidenten en vaste Drive-dagreferenties. Wanneer geen
volledig concert beschikbaar is, bereken alleen incidentpunten uit geschikte
incidentregistraties; ontbrekende analyses zijn null en geen nul. Expliciete
status complete/incomplete voor kaart en toekomstige overzichten. Onvolledige
score krijgt geen classificatie Laag/Midden/Hoog. Volledige berekening blijft
ongewijzigd. Geen extra opslag, API of dienstconfiguratie. Versie blijft V1.99.
