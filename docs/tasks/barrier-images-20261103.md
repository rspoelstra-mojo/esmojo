# Standaardafbeeldingen Barrieropstelling

Eigenaar: Codex. Branch: task/barrier-images-20261103.

Voeg de vijf door de gebruiker aangeleverde PNG's uit Archief.zip ongewijzigd
toe aan de voorbereide assetmap, onder de bestaande configuratienamen. Controleer
de koppeling en weergave. Verwachte wijzigingen: src/assets/barrier-layouts,
index.html (websiteversie V1.09) en deze taaknotitie. Geen wijzigingen in Drive,
beoordelingslogica of andere productieonderwerpen.

De vijf PNG's zijn bytegelijk aan de aangeleverde bestanden; alleen de namen
zijn aangepast aan de bestaande centrale configuratie. De README bevat de mapping.
Build en diff-check slagen. Browsercontrole: alle vijf dropdownkoppelingen,
object-fit contain, afbeelding rechts op desktop, light/dark en mobiel; geen
PNG-download voordat een opstelling is geselecteerd.
