# Projectteam-blok op het showoverzicht

Eigenaar: Claude Code. Branch: task/claude-project-team-20261117.

Gebruikersopdracht (17 november 2026): het blok Projectteam krijgt dezelfde vormgeving als Tijdschema (functie links, naam rechts), met voorlopig compleet willekeurige placeholdernamen voor Productiemanager, Event Safety manager, Projectleider TSC en CMT leider.

Uitgangspunten: alleen presentatie met vaste placeholders in code; geen echte personen, geen opslag, geen API, geen rechten- of schemawijziging. De werkelijke koppeling van personen aan de show volgt in een eigen opdracht (classificatie vooraf vragen).
Bestanden: src/show-team.js/.css, src/lib/show-team.js (+test), src/show-page.js, check.yml, versie.
