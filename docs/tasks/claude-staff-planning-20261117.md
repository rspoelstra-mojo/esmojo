# Personeelsplanning

Eigenaar: Claude Code. Branch: task/claude-staff-planning-20261117.

Gebruikersopdracht (17 november 2026): Beheerder / Personeelsplanning met tabel van alle MOJO-concerten (365 dagen, bestaande zaalfilters), drie kleurgroepen kolommen, elke functiecel een auto-opslaand tekstveld; de 05:00-run houdt de lijst bij; de waarden komen ook in het blok Projectteam op de showpagina's.

Classificatie (door de gebruiker bevestigd): namen Vertrouwelijk, opslag versleuteld in de bestaande Integratiestatus, geen nieuw schema.
Afwijking van het gekozen importvenster: een 365-dagencatalogus is niet gebouwd (zou per concert volledige Shows-structuren en automatische toewijzingen aanmaken); de lijst staat apart naast de 45-dagencatalogus.
