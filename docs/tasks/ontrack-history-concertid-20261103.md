# OnTrack-historie en concert-ID

Eigenaar Codex, deze chat. Branch task/ontrack-history-concertid-20261103.
Gebruiker wil alle zes zalen in de aparte beheerdercatalogus van één kalendermaand
terug tot één jaar vooruit. Gewone Shows/Gashouder-import niet wijzigen. Onderzoek
ook daadwerkelijke beschikbaarheid van historische MOJO-bronnen; geen fictieve
historie of handmatig hardcoded SCOOTER-record. Bestaande gegevensclassificaties
blijven gelden. Koppeling gebruikt het concert-ID uit incidents_<concert-ID>.csv
tegen canonieke opgeslagen records, niet een fuzzy artiest-/zaalgok.

Origineel grijs ON-icoon is inline aangeleverd en gezien; er is nog geen lokaal
imagebestand/Sediment-ID beschikbaar. Gebruiker gevraagd PNG als bestand toe te
voegen zodat het origineel exact kan worden overgenomen. Niet reconstrueren.
Bestanden: venster/scraper/cataloogvalidators, aparte Drive-catalogus, CSV-match,
tests en docs; PNG indien beschikbaar. Dagelijkse middagfrequentie behouden.
Websiteversie V1.25. Geen echte mails zelfstandig versturen.
