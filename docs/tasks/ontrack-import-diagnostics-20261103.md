# Diagnose eerste OnTrack-concertimport

Eigenaar: Codex, deze chat. De eerste geautoriseerde live-import bevestigt
Gashouder (37 concerten) maar de nieuwe OnTrack-catalogus geeft een generieke
fout. Voeg uitsluitend veilige foutcodes/locatie toe zodat de oorzaak kan worden
vastgesteld zonder HTML, bestandsinhoud, tokens of profielgegevens te loggen.
Bestaande gegevens blijven behouden. Afronden en de initiële import verifiëren
voordat de showrapportage verder wordt aangesloten. Zelfde lopende V1.21-scope,
geen extra zichtbare versie voor uitsluitend serverdiagnostiek.
