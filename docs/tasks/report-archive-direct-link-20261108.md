# Rechtstreekse historische rapportagelinks

Eigenaar: huidige Codex-sessie. Branch: task/report-archive-direct-link-20261108.
Gebruiker meldt dat een artiestlink naar een oude rapportage ‘niet gevonden’ geeft.
De selectie wordt onterecht alleen in de zichtbare 45-dagenmenugroepen gezocht.
Selecteer de rapportage uit de volledige geautoriseerde catalogus; behoud het
beperkte submenu en de serverautorisatie. Controleer ook de menucache op de eerder
goedgekeurde middag-/avondvoorstellingen op één datum. Geen nieuwe menuvelden in
persistente opslag, rapportagecomponenten of backend-/Drive-/importwijzigingen.
De historische import en validatie lopen onafhankelijk door.
