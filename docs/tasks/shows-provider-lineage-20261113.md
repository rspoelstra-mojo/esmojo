# Technische bronversie bij identieke actieve voorbereiding

Eigenaar huidige Codex-sessie, geautoriseerde Shows-activering.
De echte documentenvergelijking slaagt voor de geblokkeerde reeks; sourceMode is
active. Ook een actieve synchronisatie kan de tijdelijke opslagversie verhogen
zonder bedrijfsinhoud te veranderen. Behoud de historische kopiegeneratie wanneer
Native snapshotintegriteit, alle actuele documenten/velden/relaties/bestanden en
monotone broncontinuïteit dit onafhankelijk bewijzen. Geen inhoud overschrijven,
geen versiedaling accepteren en geen bedrijfscontrole overslaan.
