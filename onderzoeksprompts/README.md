# Elf bewerkbare ESMOJO-onderzoeksprompts

De genummerde MD-bestanden zijn de originele gebruikersprompts uit
ESMOJO_11_onderzoeksprompts.zip. De lokale zelfstandige skill en de beveiligde
MCP-actie research_prompt lezen dezelfde centrale bestanden; geen tweede
inhoudelijke promptkopie bijhouden.

Pas een prompt aan via een normale gecontroleerde codewijziging/publicatie.
De MCP-server geeft daarna de actuele prompt en promptRevision terug.
Een oudere gekoppelde zip in een andere agent wordt niet vanzelf bijgewerkt:
laat die agent de actuele research_prompt-actie gebruiken.

Behoud bestandsnamen, nummering, de koppen Onderzoeksvraag en Onderzoekslijnen
en het vaste antwoordformaat. Een bewuste wijziging hoeft de importhash in de
catalogue niet te vervangen; die registreert uitsluitend de oorspronkelijke bron.
Wijzig niet midden in een onderzoeksrun. Bestaande antwoorden nooit automatisch
opnieuw genereren of overschrijven. Een promptwijziging start geen onderzoek.
